# Security

Sidewalk is an early personal-use preview, not a shared multi-tenant execution service. Do not pair other people to your bridge or expose its loopback API directly. Keep `.local`, provider keys, tunnel tokens and QR codes private.

Report suspected vulnerabilities using GitHub's private security reporting for this repository when available. If it is unavailable, open an issue asking for a private reporting channel without disclosing exploit details or credentials. Never include real tokens, work content or journal files in public reports.

Known boundaries and retention limitations are documented in docs/privacy.md. There is no guarantee of response time or enterprise support. Contributions that improve isolation, revocation, startup/recovery and deployment safety are welcome.
